# Pokémon TCG Pocket graphics

Card artwork, names and game symbols belong to their respective Pokémon rights holders. Graphics are prepared for the HeyHans catalog.

Rarity, expansion, booster and energy graphics: https://github.com/Vociferix/ptcgp-images/tree/07fb815e5834de10d9218b53abe0e6e4940157b7 (repository code MIT; artwork rights remain with the original rights holders).

Card illustrations are deduplicated by the game card identifier. Full images retain their native proportions; thumbnails are WebP. No account credentials, player data, private application code or commercial order data are included.
