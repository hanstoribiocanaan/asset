# HeyHans Asset

Biblioteca pública de recursos visuales compartidos por:

- `heyhans.app`
- TradeBot / SysBot
- Integraciones y mensajes de Discord

## Estructura

- `badges/buyer-tiers/`: insignias de fidelidad para compradores.

Los consumidores deben usar URLs CDN versionadas por commit. De esta forma, una actualización futura no modifica imágenes ya publicadas ni consume transferencia estática de Vercel.

Los recursos son propiedad visual de HeyHans. Su publicación permite que los clientes oficiales los descarguen; no concede una licencia de reutilización externa.
