# SV-style menu artwork for HOME

Original, unmodified PNGs from kwsch/PKHeX commit 0660d1e1f4924b8478daec73281bb8071a82ad19, Resources/img/Artwork Pokemon Sprites. Full SV-style collection introduced by sora10pls and SciresM in 3e6a036c549c3b2fbb5cbea3a3d9806f5c07b215. ProjectPokemon reference: https://projectpokemon.org/home/docs/spriteindex_148/switch-sv-style-sprites-for-home-r153/

Current upstream includes normalized Champions artwork (4d2181d751ef0b9df3561987792b7e6af836a417). The consumer prefers its separately pinned original 128x128 Champions normal/shiny collection; this complete 68x56 menu corpus supplies missing identities. Neither Legends Z-A icon packs nor HOME 3D renders are used. Missing shiny artwork uses an explicitly described normal menu illustration, retaining the real shiny attribute independently.
